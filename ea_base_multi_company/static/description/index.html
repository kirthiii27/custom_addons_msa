Frequently Asked Questions

Find quick answers to common questions about Multi Company Base.

How does this module enable multi-company support?

By inheriting the multi.company.abstract model in your custom or extension modules.

Does it replace Odoo's standard single company_id field?

It extends single-company support by adding a company_ids field while dynamically computing company_id.

Can I use this base module for any Odoo model?

Yes. Any model inheriting multi.company.abstract gains multi-company support.

Does it require additional configuration after installation?

No. Install the module and inherit it in your desired models.

Is it compatible with Odoo 19 Community Edition?

Yes. The module is fully compatible with Odoo 19 Community and support standard product and inventory management.
